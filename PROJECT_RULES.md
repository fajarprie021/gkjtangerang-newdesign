# Project Rules

- This is a legacy CodeIgniter 3 application.
- Do not modify controllers, models, routes, or backend business logic unless explicitly asked.
- Focus only on views and front-end assets.
- Preserve existing PHP variables and data bindings in views.
- Prefer creating new view variants instead of overwriting old files immediately.
- Use Tailwind CSS for styling.
- Keep implementation simple and easy to maintain.
- Avoid introducing React, Vue, Vite, or Node-based runtime dependencies unless explicitly requested.
